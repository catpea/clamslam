# Roadmap

## v0.6

- Split demo runtime into reusable modules.
- Add a minimal XML parser/compiler prototype.
- Compile `<props>`, `<view>`, `<drag>`, `<connect>`, and `<dev><probes>` into JavaScript.
- Add browser-based fixture runner.

## v0.7

- Publish `gizmo/core` and `gizmo/node-editor` package boundaries.
- Add custom element registration from `.gizmo.xml` files.
- Add source maps from generated JavaScript back to XML nodes.

## v1.0

- Stable language grammar.
- Stable runtime API.
- Cross-browser probe runner.
- Local AI conversion skill and validation workflow.
